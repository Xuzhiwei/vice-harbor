Vice Harbor is an original top-down open-world crime game that runs entirely in the browser. You roam a sun-soaked coastal city on foot or behind the wheel, weaving through traffic and crowds of pedestrians, stealing cars and driving them hard. Cause enough trouble and the five-star wanted system kicks in, sending the police after you in escalating pursuit. Combat is mouse-aimed, and a six-mission story — dealt out by five original characters — threads through the sandbox, while taxi fares and lost packages offer quicker ways to earn side cash. A minimap HUD keeps you oriented, a full day/night cycle rolls over the harbor, and your progress is kept in a localStorage save. The whole thing is pure canvas and WebAudio: no build step, no network calls, and every asset is generated procedurally in code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser (or serve the `game/` folder with any static file server and open `game/index.html`).

**Controls:** WASD/arrows move, Shift sprint, E enter/exit car, Space handbrake, mouse aim + click to shoot, F melee, R reload, Esc pause, M mute.
