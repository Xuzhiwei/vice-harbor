Vice Harbor is an original top-down open-world crime game for the browser: a sun-soaked coastal city you explore on foot and by car, with traffic and pedestrians, cars to steal and drive, a five-star wanted system with police who pursue and pin you, mouse-aimed combat, a six-mission story from five original characters, taxi fares and lost packages for side cash, a minimap HUD, a day/night cycle, and a localStorage save. Pure canvas and WebAudio — no build step, no network, every asset procedural.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 (or serve the `game/` folder with any static file server and open `game/index.html`).

Controls: WASD/arrows move, Shift sprint, E enter/exit car, Space handbrake, mouse aim + click to shoot, F melee, R reload, Esc pause, M mute.
